# GUI-Based Data Cleaning Automation Using Python

## Project Overview
A desktop GUI application developed using Python to automate Excel data-cleaning operations.

## Features
- Remove duplicate rows
- Remove blank rows
- Remove leading and trailing spaces
- Convert text columns to Title Case
- Select input Excel file
- Choose output folder

## Technologies Used
- Python
- Pandas
- OpenPyXL
- Tkinter (if used)

## Installation

Install the required libraries:

pip install pandas openpyxl

## How to Run

python data_cleaning_automation.py
